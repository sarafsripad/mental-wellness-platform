This page drives the real API with your Keycloak login. It can only send generated test audio: there is no microphone and no file upload, so no real voice can be labelled as synthetic. Log in as asha.test1 or asha.test2 (password: KEYCLOAK_TEST_USER_PASSWORD in deploy/local/.env). Try clinician.test1 or admin.test1 to see access rules refuse you.
